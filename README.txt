=====================================================================
PORTOFOLIO RESMI - REZA DWI KURNIAWAN
Web Portofolio Modern Dual-Theme (Mode Gelap & Mode Terang)
Teknologi: C++, HTML5, CSS3, & JavaScript (ES6+)
=====================================================================

✨ FITUR UNGGULAN & PEMBARUAN TERBARU:

1. Sistem Tema Ganda Cerdas (Dark Mode & Light Mode):
   - Mode Gelap (Dark Mode): Estetika Cyber Obsidian (#06090e) dengan aksen neon Electric Cyan (#00f5d4), orbit holografik, dan glassmorphism elegan.
   - Mode Terang (Light Mode): Tampilan bersih, kontras tinggi, modern minimalis profesional dengan aksen teal/cyan dan bayangan lembut.
   - Switcher tema instan di Navigation Bar dan Footer.
   - Penyimpanan otomatis preferensi tema di LocalStorage browser.
   - Transisi CSS warna yang sangat halus saat berganti tema tanpa kedipan kasar.

2. Laboratorium Interaktif C++, HTML, & JavaScript (Interactive Code Hub):
   - C++ Simulator Nyata di Browser:
     * Program 1: Cek Bilangan Ganjil & Genap (Logika Modulus).
     * Program 2: Kalkulator Sederhana (Percabangan Switch-Case C++).
     * Program 3: Konversi Satuan Waktu (Detik ke Jam, Menit, & Detik).
     * Dilengkapi input pengguna langsung, terminal output bergaya Linux/macOS, dan tombol salin kode C++.
   - HTML5 Semantics Lab:
     * Panduan struktur dokumen standar W3C, tag semantik (<header>, <main>, <article>, dll), dan pohon hierarki DOM.
   - JavaScript Playground:
     * Uji coba manipulasi DOM secara langsung, pengubah warna aksen dinamis, dan kode pengontrol tema.

3. Desain Visual & Pengalaman Pengguna (UX/UI):
   - Efek 3D Card Tilt interaktif yang merespons posisi mouse.
   - Cincin orbit animasi (Dual Orbiting Rings) di sekeliling foto profil Reza Dwi Kurniawan.
   - Efek partikel konstelasi (Ambient Canvas) yang dinamis menyesuaikan kecerahan tema.
   - Cursor glow halus pada tampilan desktop.
   - Dynamic typing animation pada hero subtitle.
   - Counter animasi angka otomatis saat di-scroll.
   - Filter tab keahlian (Semua Stack, Web & Frontend, Logika & C++, Tools & Git).
   - Modal preview screenshot proyek beresolusi tinggi (ESC / klik backdrop untuk menutup).
   - Tombol salin alamat email instan (rdwik1190@gmail.com) lengkap dengan Floating Toast Notification.
   - Formulir pesan langsung dengan validasi input interaktif.

📁 STRUKTUR FILE PROYEK:
- index.html   : Kerangka semantik HTML5, meta tag SEO, struktur konten, dan aksesibilitas ARIA.
- style.css    : Sistem desain CSS variabel, dual-theme, glassmorphism, responsive grid (Mobile hingga 4K).
- script.js    : Logika Vanilla JS murni (theme switcher, canvas, C++ simulator, modal, form validation, filter).
- CV_Reza_Dwi_Kurniawan.pdf : Berkas CV resmi Reza Dwi Kurniawan (PDF) yang ditautkan ke tombol "Lihat CV".
- README.txt   : Dokumentasi dan panduan cara menjalankan.
- images/      : Direktori aset visual:
    * foto-reza.jpeg
    * bilangan-ganjil-genap.png
    * kalkulator-sederhana.png
    * konversi-waktu.png

🚀 CARA MENJALANKAN DI KOMPUTER / LAPTOP:
1. Buka folder "portofolio" di Visual Studio Code.
2. Klik kanan file "index.html".
3. Pilih "Open with Live Server" (atau klik dua kali file index.html langsung di File Explorer untuk membukanya di browser Google Chrome / Microsoft Edge / Brave).
4. Klik tombol "Mode" di pojok kanan atas untuk beralih antara Mode Gelap dan Mode Terang.
5. Coba bagian "C++ & Web Lab" untuk berinteraksi langsung dengan simulasi program C++, HTML, dan JavaScript!
